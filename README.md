## 🧠 Pilares da Formação

O curso foi estruturado a partir de uma abordagem holística, dividida em quatro grandes eixos de evolução:

### 1. Hard Skills (Desenvolvimento Técnico)
- **Desenvolvimento Mobile:** criação de interfaces modernas e declarativas utilizando **Kotlin** e **Jetpack Compose** no **Android Studio**.
- **Desenvolvimento Backend:** construção de APIs robustas com **Spring Boot** e manipulação de dados em formato **JSON**.
- **Banco de Dados:** modelagem e persistência de dados utilizando o banco não-relacional NoSQL **MongoDB**.
- **Inteligência Artificial:** estudo e integração de conceitos de IA aplicados ao desenvolvimento de software.

### 2. Metodologias Ágeis
- Gerenciamento e organização do fluxo de trabalho através do framework **Scrum**, simulando o ritmo e a dinâmica de equipes reais do mercado de tecnologia.

### 3. Soft Skills (Preparo Comportamental e de Carreira)
- Treinamentos focados em comunicação, inteligência emocional e postura profissional.
- **Simulações de Processos Seletivos:** vivência prática de dinâmicas de contratação e entrevistas técnicas/comportamentais.
- **Experiências Culturais:** atividades complementares voltadas à ampliação de repertório social e crítico.

### 4. Projeto Profissional Aplicado
- Desenvolvimento prático e incremental de um projeto de conclusão de curso, integrando todas as competências adquiridas.

---

## 🛠️ Projeto de Destaque: Cattleya

Durante o programa, foi idealizado e desenvolvido o **Cattleya**, um projeto prático estruturado sob metodologias ágeis e utilizando a stack nativa de Kotlin e Spring Boot com MongoDB. O projeto serviu como consolidação prática de todo o ecossistema aprendido em sala de aula.
